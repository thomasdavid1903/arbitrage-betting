How long a price stands before it moves

Each price carries the bookmaker's own changedAt, so one scan already records how long that price had been standing. Bars span the 25th to 75th percentile; the notch is the median. This is the clock your script has to beat.

Movement by time to kick-off

Pooled across every bookmaker, so the slow books dominate these medians — the sharp book alone is far quicker. Fixtures days out barely move; the near ones do. Sample sizes inside 24h are small, so read the direction rather than the exact figure.

Age distribution

Every observed price, log-binned. The left tail is the live market; the right is fixtures nobody has repriced yet.

Overround across scans

Best and median overround each time you scanned. With one or two scans on file this is a couple of points; it becomes the trend line as scans accumulate.

Stored data

Scans append to data/scans.jsonl (one JSON object per scan) and every individual price to data/prices.csv (long format, one row per price per book per scan). Neither file is ever rewritten, so this page and any analysis you run later read from disk rather than the API.
